
# E-commerce UI Improvement – Bách Hóa Xanh

## Giới thiệu dự án
Bài tập cá nhân cải tiến giao diện trang chủ Bách Hóa Xanh bằng HTML5 và CSS3.

Website tham khảo: https://www.bachhoaxanh.com/

## Vấn đề và giải pháp
Trang chủ có nhiều banner và danh mục, có thể gây khó khăn trong việc xác định nội dung quan trọng. Dự án thiết kế lại banner, danh mục nổi bật, khu vực sản phẩm và giao diện responsive.

## Công nghệ
HTML5, CSS3, CSS Grid, Flexbox và Media Queries.

## Hướng dẫn chạy
Mở index.html bằng trình duyệt hoặc Live Server trong VS Code.

## Điều chỉnh cá nhân
Cải tiến thanh điều hướng bằng CSS Grid để chia đều bốn mục menu, bổ sung hiệu ứng hover với nền xanh nhạt và góc bo tròn.

## Lưu ý
Đây là bản demo học tập, không phải website chính thức của Bách Hóa Xanh. Các sản phẩm và giá bán chỉ mang tính minh họa.
